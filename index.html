FMCG Acquisition Data Unification Lakehouse

Designed and deployed an end-to-end Medallion Lakehouse on Databricks to resolve multi-source data bottlenecks following the acquisition of a high-growth nutrition startup (Sportsbar) by a global sports equipment manufacturer (Atlikon).

  • Data Ingestion: Centralized chaotic multi-source inputs (APIs, CSV exports, spreadsheets) into Amazon S3 storage buckets.
  • Processing Strategy: Built historical backfill pipelines for 5 months of batch data alongside an automated incremental pipeline for ongoing updates.
  • Medallion Design: Implemented Bronze (raw), Silver (cleansed/validated), and Gold layers with Databricks Unity Catalog governance.
  • Dimensional Modeling: Modeled a high-performance Star Schema (1 Fact Order table + 4 Dimension tables) merging startup and enterprise operations into a unified BI layer.

Declarative Lakehouse & Auto-CDC Platform

Built an automated, declarative lakehouse pipeline using Databricks LakeFlow and Medallion Architecture for "Good Caps" transportation network, eliminating late operational reporting and manual query restructuring across regional hubs.

  • Declarative Pipelines: Replaced procedural scripts with LakeFlow Spark Declarative Pipelines (SDP) and materialized views, letting Spark handle dependency management and execution optimization.
  • Data Quality & CDC: Ingested dimensional and transactional files from S3 with automated cloudFiles, applied Silver layer data quality Expectations, and implemented Auto CDC for slowly changing dimensions (SCD).
  • Temporal & Aggregated Gold Views: Programmatically generated a custom calendar dimension and built Gold-layer aggregations (driver/passenger ratings, trip counts, regional revenue).
